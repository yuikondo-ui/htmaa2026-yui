Data Blocks

No frame. Visitors snap together 10 cm acrylic blocks with magnets inside, each engraved with a fragment of my body. Only blocks connected to the base get power and light up. The faint outline is my body scan; the blocks are free to grow past it.

How it could work

A free-spinning spherical magnet in the centre of each face lets any face snap to any other. A ring of metal contacts around each magnet passes power from block to block, so only blocks connected to the base light up, with no batteries.

Magnets are weak in shear, so long overhangs fall off. Blocks mostly need support from below, and the base should be heavy.
